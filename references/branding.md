# Optional branding

Brand configuration has three modes:

| Mode | Meaning | Public claim boundary |
| --- | --- | --- |
| `none` | No brand assets or attribution | Default; no personal attribution is implied. |
| `subtle` | Small replaceable footer or documentation mark | Never implies project ownership or endorsement. |
| `full` | Owner-approved visual treatment and documented assets | Requires source, rights, accessibility, and replacement plan. |

The BOOMKALAKASHA kit in `assets/brand/boomkalakasha/` is a locally validated example profile. It supplies a watermark and a square avatar asset; it is not a mandatory project default and it must not be copied into a project without the relevant owner choice. The deterministic [guidelines](../assets/brand/boomkalakasha/brand-guidelines.md) and [specimen](../docs/brand/preview.html) cover its local usage. Changing a public personal profile/avatar is a separate, explicit action.

For any asset, record creator/source, license or permission evidence, modification status, accessible alternative text, light/dark treatment, smallest usable size, and removal/replacement path. Do not treat a local SVG or image scan as trademark or copyright approval.
