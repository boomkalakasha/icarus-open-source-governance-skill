# Licensing boundary

Choose a license only for material the maintainer is entitled to license. Software license selection, third-party notices, images/fonts, copied prose, employer ownership, customer confidentiality, and trademark use are separate questions.

This Skill does not advise which license is legally correct. Compare current primary sources such as the [Open Source Initiative license list](https://opensource.org/licenses) and [SPDX](https://spdx.dev/learn/), then obtain the required owner or legal decision. Record that decision in the configuration and release ledger; keep it `review-required` when evidence is incomplete.
