# RED baseline summary

Three Luna Max runs were executed on 2026-08-25 before `SKILL.md` existed.

## Observed strengths without the Skill

- The model already refused unsafe same-day publication.
- It separated current-tree, Git history, commit metadata, license, brand, build, artifact, and remote evidence.
- It correctly routed a private Jenkins/customer-branch request away from public OSS governance.

## Discriminating gaps the Skill must close

- Baseline outputs are long advisory reports rather than a repeatable repository workflow.
- They do not share a machine-readable configuration contract or reusable output templates.
- They do not provide deterministic validators/scanners with tested exit behavior.
- Brand choices are discussed but not represented as `none`, `subtle`, or `full` configuration profiles.
- Evidence states and release gates are not emitted in one reusable manifest/ledger format.
- The three answers use different structures, increasing drift across agents and projects.

The Skill therefore must not merely repeat safety advice. Its value is consistency, executable checks, configurable branding, bilingual templates, and one auditable public-release gate.
