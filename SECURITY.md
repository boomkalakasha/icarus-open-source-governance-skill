# Security policy

Do not post credentials, private repositories, customer data, exploit details, or unpublished scan findings in a public issue.

Use the repository's private vulnerability-reporting channel when it is enabled. Until a maintainer publishes a verified channel, ask for a secure contact path through the repository owner rather than guessing an address. Include affected version/commit, reproducible steps, impact, and any safe remediation idea.

This repository provides governance guidance and deterministic checks; it does not promise a response SLA, security certification, or production monitoring.
